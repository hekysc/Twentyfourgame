# 🧪 1. 微信账号登录相关（WeChat Login）

### TC-WX-001：首次微信登录创建新账号

* **前置条件**

  * 当前设备未登录
  * 该微信 openid 在 user 表中不存在

* **步骤**

  1. 启动小程序/APP，进入登录方式选择页
  2. 点击「微信登录」
  3. 微信弹出授权窗口，点击「允许」
  4. 前端调用 `wx.login` → 发送 code 至 login 云函数（scene=mp-weixin）

* **预期结果**

  * 云端调用 jscode2session 成功返回 openid
  * user 表新增一条账号记录：

    * `account_type = 'weixin'`
    * `openid` 正确
    * `device_id` 为空或可选
  * 云函数返回 token 与 user 信息
  * 前端缓存 token 与 user，并跳转至首页

---

### TC-WX-002：重复微信登录（已有账号）

* **前置条件**

  * user 表中已有对应 openid 的微信账号记录

* **步骤**

  1. 启动小程序
  2. 点击「微信登录」
  3. 正常授权后，调用 login(scene=mp-weixin)

* **预期结果**

  * 不创建新用户
  * 查到原有记录并更新 `last_login_at`
  * 返回 token 与该微信账号的 user 信息
  * 用户在首页看到的是之前的账号数据（分数、进度等保持不变）

---

### TC-WX-003：微信授权拒绝

* **前置条件**

  * 用户未授权微信登录

* **步骤**

  1. 点击「微信登录」
  2. 在授权弹窗中选择「拒绝」

* **预期结果**

  * 不调用 login 云函数
  * 前端提示「授权失败，您可以稍后在设置中重新授权」或类似友好文案
  * 保留在登录方式选择页

---

### TC-WX-004：微信登录异常（code 无效）

* **前置条件**

  * 模拟网络错误 / jscode2session 返回错误

* **步骤**

  1. 点击「微信登录」
  2. 人为修改云函数逻辑或模拟微信接口返回错误（errcode != 0）

* **预期结果**

  * 云函数返回错误 `微信登录失败` 文案
  * 前端提示「微信登录失败，请稍后重试」
  * 不进入首页，不写入本地登录状态

---

# 🧪 2. 普通账号创建（Local Account Create）

### TC-LC-001：正常创建普通账号

* **前置条件**

  * 本机可用，local_accounts 可为空或已有其它账号

* **步骤**

  1. 在登录方式选择页，点击「普通账号登录」
  2. 在普通账号列表页，点击「新建普通账号」
  3. 输入昵称「小明」
  4. 选择一枚系统预置头像
  5. 点击「创建并登录」

* **预期结果**

  * 本地存储 local_accounts 增加一条记录：

    * 有新生成的 `user_id (UUID)`
    * `nickname = 小明`
    * `avatar_url` 为选中头像
  * 云端 user 表新增对应记录：

    * `account_type = 'local'`
    * `device_id` 为当前设备 ID
  * 自动登录成功，进入首页

---

### TC-LC-002：创建普通账号昵称重复

* **前置条件**

  * 本机已有普通账号：昵称为「小明」
  * 允许昵称重复

* **步骤**

  1. 新建普通账号
  2. 再次输入昵称「小明」
  3. 选择任意头像
  4. 点击「创建并登录」

* **预期结果**

  * 本地新增一个账号，昵称相同但 `user_id` 不同
  * 云端 user 表中新增一条 record，nickname=小明，但 user_id 与其他账号不同
  * UI 不提示「昵称已被占用」之类的错误

---

### TC-LC-003：创建普通账号不选头像

* **前置条件**

  * 有默认头像逻辑（如随机选一枚预置头像）

* **步骤**

  1. 新建普通账号
  2. 输入昵称「测试用户」
  3. 不选任何头像（不触发上传/点击）
  4. 点击「创建并登录」

* **预期结果**

  * 系统自动为该账号设置一枚默认头像
  * 本地与云端都有对应 avatar_url
  * 登录成功

---

### TC-LC-004：创建普通账号时断网

* **前置条件**

  * 模拟设备当前无网络（或云函数调用失败）

* **步骤**

  1. 断开网络
  2. 尝试创建普通账号
  3. 点击「创建并登录」

* **预期结果**

  * 本地 local_accounts 可以先写入（视设计而定）
  * 调用云函数失败时，前端提示「网络异常，稍后自动同步」或禁止创建成功（按你最终设计）
  * 需明确：

    * A 方案：先本地建号，网络恢复后后台同步
    * B 方案：创建失败，要求联网

（这里 PRD 里要定一条策略，测试按那条测）

# 🧪 3. 普通账号登录本机（Local Login）

### TC-LL-001：登录本机普通账号成功

* **前置条件**

  * local_accounts 中已有：user_id=U1，device_id=binding=当前设备
  * 云端 user 表中有对应账号记录

* **步骤**

  1. 打开普通账号列表页
  2. 点击账号「小明」
  3. 系统获取当前 device_id，并调用 login(scene=app, user_id=U1, deviceId=当前设备)

* **预期结果**

  * 云端校验通过（device_id 匹配）
  * 返回 token 与 user 信息
  * 登录成功，进入首页

---

### TC-LL-002：本机有多个普通账号，切换登录

* **前置条件**

  * 本机 local_accounts 至少有两个账号 U1、U2

* **步骤**

  1. 登录 U1，进入首页并查看其数据（如分数 100）
  2. 返回登录页 → 普通账号列表
  3. 点击账号 U2
  4. 登录 U2，进入首页查看数据（如分数 30）

* **预期结果**

  * 第一次登录显示 U1 数据
  * 第二次登录显示 U2 数据，与 U1 数据不同
  * 切换账号不会影响另一个账号的数据

# 🧪 4. 普通账号跨设备限制（Single Device Binding）

### TC-DEV-001：尝试在另一台设备登录普通账号（禁止）

* **前置条件**

  * 设备 A：存在本地账号 U1（device_id=A），并与云端绑定
  * 设备 B：没有该账号的本地记录

* **步骤**

  1. 在设备 B 手动构造请求（开发接口工具）调用 login(scene=app, user_id=U1, deviceId=B)

     > 或通过调试模拟这个请求

* **预期结果**

  * 云端查找 user_id=U1
  * 比对 device_id 发现不匹配（A != B）
  * 返回错误：如「此账号仅限本机使用」
  * 不返回 token、不允许登录

---

### TC-DEV-002：本机更换系统 / 重装 App 导致 device_id 改变

> 此用例需结合你最终 device_id 策略测试
> 如 plus.device.uuid 是否稳定、是否变更后视为新设备。

* **前置条件**

  * 设备升级 / 重装后 device_id 变化

* **步骤**

  1. 创建普通账号
  2. 升级系统 / 卸载重装 App，确认 device_id 发生变化
  3. 再次尝试登录该普通账号（如果本地记录仍在）

* **预期结果**

  * 云端校验失败（device_id 不匹配）
  * 前端提示：该账号已失效或仅限旧设备使用（需 PRD 定义文案）

# 🧪 5. 普通账号 → 微信账号升级（Upgrade）

### TC-UP-001：本机普通账号升级绑定微信（目标 openid 无账号）

* **前置条件**

  * 本机已有普通账号 U1：account_type=local
  * openid 对应的微信账号在 user 表中不存在

* **步骤**

  1. 登录普通账号 U1
  2. 打开“账号设置/我的账号”页
  3. 点击「升级为微信账号」
  4. 在弹出的授权中，同意微信登录
  5. 前端调用 login(scene=upgrade, code, old_user_id=U1)

* **预期结果**

  * 云端通过 code 获取 openid
  * 查 openid 不存在 → 直接将 U1 记录更新为：

    * account_type = weixin
    * openid = 获取到的 openid
  * 返回新的 token 与 user 信息（微信账号）
  * 前端更新 UI 显示为“已使用微信登录”
  * 之后通过微信登录可以取到同一数据

---

### TC-UP-002：普通账号升级绑定微信（目标 openid 已有微信账号）

* **前置条件**

  * user 表中已有微信账号 W（openid = X）
  * 本机还有普通账号 U1（无 openid，有独立 stats 数据）

* **步骤**

  1. 登录普通账号 U1
  2. 点击“升级为微信账号”
  3. 使用已有微信账号 W 授权
  4. 调用 login(scene=upgrade, code, old_user_id=U1)

* **预期结果**

  * 云端获取 openid = X，发现已有账号 W
  * 按合并策略：

    * 将 U1 的 stats/进度合并到 W（具体规则按 PRD：累加、取最大、覆盖等）
  * 可选：删除 U1 or 标记为 merged
  * 返回 W 的 token 与合并后的 user 信息
  * 前端表现为：

    * 当前账号变成微信账号
    * 数据为合并结果

---

### TC-UP-003：升级过程中取消微信授权

* **前置条件**

  * 普通账号 U1 已登录

* **步骤**

  1. 在“升级为微信账号”流程中点击「升级」
  2. 微信授权弹窗出现
  3. 用户点击「拒绝」

* **预期结果**

  * 不调用 upgrade 场景的登录云函数
  * 仍然保持普通账号 U1 登录状态
  * UI 提示「授权失败，升级未完成」

# 🧪 6. 本机多账号管理（Local Account Management）

### TC-LM-001：删除普通账号（本地 & 云端）

* **前置条件**

  * 本机有普通账号 U1
  * 云端有对应记录

* **步骤**

  1. 在普通账号列表页，长按 U1
  2. 选择「删除账号」
  3. 弹出二级选项「仅本机删除 / 本机和云端一起删除」
  4. 选择「本机和云端一起删除」

* **预期结果**

  * 本地 local_accounts 中移除 U1
  * 云端 user 表中删除该用户或标记为 deleted
  * 日后通过任何方式均不可再登录该账号

---

### TC-LM-002：删除普通账号（仅本机删除）

* **步骤**

  1. 同上，但选择「仅本机删除」

* **预期结果**

  * 本地 local_accounts 移除 U1
  * 云端 user 记录保留
  * 从产品定位上，不再提供恢复途径（除非你设计“恢复本机账号”的隐藏通道）

---

### TC-LM-003：编辑普通账号昵称与头像

* **前置条件**

  * 普通账号 U1 已存在

* **步骤**

  1. 在普通账号列表页，进入 U1 的账号设置
  2. 修改昵称为「小明-修改版」
  3. 更换头像
  4. 点击保存

* **预期结果**

  * 本地记录更新
  * 云端 user 表的 nickname / avatar_url 同步更新
  * 重新登录后显示新昵称和新头像

# 🧪 7. 安全与异常（Security & Error Handling）

### TC-SEC-001：伪造 user_id 登录（本机不存在）

* **前置条件**

  * 调试工具构造一个不存在于本机 local_accounts 的 user_id

* **步骤**

  1. 直接调用 login(scene=app, user_id=FakeID, deviceId=真实设备)

* **预期结果**

  * 云端可能找不到 user 或直接拒绝
  * 前端应把这视为非法请求，不进入登录状态

---

### TC-SEC-002：伪造 token 访问业务接口

* **前置条件**

  * 客户端缓存了一个合法 token
  * 手动改写 token（随便串）

* **步骤**

  1. 构造请求，调用需要鉴权的云函数（如 game/report）
  2. 使用伪造 token

* **预期结果**

  * auth 校验失败
  * 返回错误 `CHECK_TOKEN_FAILED` 或等价错误码
  * 不允许访问业务数据，不修改任何云端记录

---

### TC-SEC-003：token 过期后访问业务接口

* **前置条件**

  * 已登录
  * 手动等待 token 过期 或 调整过期时间模拟

* **步骤**

  1. token 过期后调用业务接口
  2. 或由服务器主动判定 token 已失效

* **预期结果**

  * 返回 `TOKEN_EXPIRED`
  * 前端收到提示需重新登录
  * 不允许访问受保护资源
